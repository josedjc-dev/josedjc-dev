## How I work

- I build with the handoff in mind. My project documentation explains what changed, how to run it, what to expect, and how to clean up afterward.
- I turn working examples into short exercises so developers and clients can follow the data, verify a result, and understand what to check if something breaks.
- I use OpenAI Codex to assist with implementation, testing, and documentation. I set the direction, work through the exercises, and review changes before deciding what to merge.
